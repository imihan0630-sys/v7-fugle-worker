# 11｜D16＋D18 市場廣度部分識別：獨立窮舉反證

日期：2026-10-11；性質：研究限定、合成數學驗證，非台股實際績效。

## 新增驗證
本輪在本地以 Python 分數精確運算（不依賴研究函式的浮點結果）窮舉：
- 已知上漲、下跌、持平家數各為 0 至 3；
- 未知家數為 0 至 4；
- 將未知家數配置到上漲、下跌、持平、不可比較四類；
- 排除完整母體中可比較分母為零的配置，該情況另標示無可比較支持；
- 共檢查 319 組具有至少一個可比較可能配置的輸入組合；
- 319 組全部與解析下界 (上漲−下跌−未知)/(已知可比較＋未知) 及上界 (上漲−下跌＋未知)/(已知可比較＋未知) 一致，沒有找到反例。

此驗證只支持給定分類假設下的確定性識別界限；不是統計信賴區間，也不是 319 個市場日期或 319 次交易。

## 證據邊界與反證
支持機制：最不利配置為未知全部下跌，最有利配置為未知全部上漲。不可比較股票不應補成持平。

反證：若同一交易日期母體未凍結、已知分類本身不可信、來源時間晚於決策截點，則上述公式即使數學正確也不能當作真實市場結論。

替代解釋：正負廣度翻轉可能來自來源覆蓋差異、分類不一致或資料收集延遲，而非策略訊號。

失效條件：歷史母體回填、未知補零、將重複證券或多期間當成獨立樣本、來源雜湊字串未驗證、以識別界限冒充機率顯著性。

## 關鍵限制
- 319 組是合成窮舉，不是前瞻觀察。
- 前輪 25 個本地測試使用備援套件程式，尚非本分支的遠端持續整合證據。
- 來源時點旗標及雜湊字串目前由呼叫端傳入，尚無不可變來源實體證明。
- 未開啟報酬結果，未修改任何正式成熟度或交易核心。
