## DL-006A — A causal multi-scale graph

A weekly Cup may contain a daily W, a later daily VCP and a local Sakata candle. These are four descriptions, not four independent votes. Define each observed object with symbol, semantic-space version, source-bar hashes, scale, layer, first/last eligible symbol-session, confirmedAt, asOf, anchor IDs, immutable boundary ID/version, and a root evidence-source list. A weekly aggregate is formed exclusively from eligible, verified constituent daily bars available by asOf; a partial current week must be marked PARTIAL and never passed off as a completed weekly candle. A weekly swing at week-ending t enters the graph only after its own confirmation time, not at the historical pivot date. Daily child observations cannot inherit a future weekly parent retrospectively.

Use directed edges with distinct semantics:
- CONTAINS: verified child's eligible-session interval falls inside the parent's interval and both refer to the same symbol and compatible technical-price space; weekly-to-daily containment is possible but does not imply extra predictive information.
- REFINES: a daily structure supplies a more precise time/price location for a confirmed parent component, with anchor mapping and boundary version recorded. This requires evidence, not merely intersecting date ranges.
- SHARES_ANCHORS: exact or measured Jaccard overlap of verified underlying daily source-bar/anchor IDs. Cross-scale symbolic IDs alone cannot establish disjointness.
- SHARES_TRIGGER: same symbol, immutable boundary ID/version, direction and first break event; a weekly rim and daily neckline with different boundaries remain separate observed events even if on the same date.
- CONTRADICTS: e.g., a purported daily continuation VCP has incompatible prior trend, or a later confirmed weekly parent is already invalidated. Record both objects and chronology; do not erase the earlier as-of snapshot.

Deduplicate within each evidence root by source-bar ancestry and trigger identity; retain distinct layer and scale attributes. Keep overlap as a continuous descriptor, with null when ancestry is unverified. Do not turn transitive edges into equivalence: weekly Cup CONTAINS daily W and daily W overlaps daily VCP does not prove Cup and VCP share an exact anchor set. Do not sum parent and children as independent confirmation; no score or sign is authorized.

Counterexamples: (1) same anchor prices but different ex-rights continuity versions -> provenance conflict, not match; (2) daily W confirmed Monday, weekly Cup only confirmed Friday -> Monday snapshot has no confirmed Cup parent; (3) two daily W candidates partially overlap under the same Cup -> retain both ambiguous alternatives; (4) weekly candle spans suspension pseudo-bars -> verified eligible constituents only; (5) weekly rim refined into a new boundary version -> do not inherit earlier break lifecycle. This graph is a specification for research QA; no historical prospective rows are created.

## DL-006B — Continuous breakout path descriptors

For each immutable boundary/version and direction, measure only on eligible symbol-sessions as of the observation timestamp. Preserve the existing causal states. Add descriptive fields: eligibleBarsSinceBreak; eligibleBarsAboveBoundary / eligibleBarsInsideZone / eligibleBarsBeyondFailureEdge; fractionAboveBoundary (denominator: eligible observed sessions since first confirmed break, explicitly excluding constrained/unobservable sessions); longest and current consecutive above-boundary run; max favorable intraday extension and max closing extension relative to the boundary in price and ATR units when ATR has PIT provenance; first reentry/failure/reclaim eligible-session offsets; time under/inside boundary before reclaim; maximum adverse excursion relative to boundary; cumulative signed distance of closes above the relevant edge; and the dated path of close positions. For DOWN use mirrored definitions. No-follow-through is an observed path description such as low positive extension and short persistence, not a Boolean failure verdict or a retrospectively optimized N-day cutoff.

Report observation status with every descriptor: NOT_BROKEN, CONSTRAINED_UNRESOLVED, PARTIALLY_OBSERVED, OBSERVABLE or DATA_BLOCKED. Values requiring future bars are null at prior as-of timestamps; zero is reserved for a genuinely observed zero. The break bar itself must be counted consistently, unlike the existing maxObservedExtension helper that updates extension only on later iterations; record both break-bar-inclusive and post-break extension explicitly. Do not include a future price-limit release as a past observation. A reclaim after failure does not erase failure; multiple episodes require separate immutable episode IDs and current-vs-first chronology. When boundary version changes, close the old path and start a new one, with no copied offsets. Calendar days, market-wide open days and symbol eligible sessions are different denominators; expose the denominator.

Falsification: a high that pierces but closes within the zone is a rejected pierce, not a confirmed break; retest staying above the upper edge is not failure; a gap jump during corporate-action reset is not automatically extension; delayed first unconstrained session means persistence is still UNKNOWN, not weak. Any future outcome test must compare these descriptors against existing 15m execution, momentum, priorHigh20/60, close location, volatility, price-volume and regime controls. No preselected direction or score.

## DL-006C — Three Gaps and the session contract

There are at least three different notions: overnight open-minus-prior-close, non-overlap interval gap (today low > prior high or today high < prior low), and a continuity-space gap after adjustment. They must carry separate type and sign. A Three-Gaps sequence is only three qualifying events under one preregistered gap definition, direction and eligible-session adjacency rule; interrupted sequences or competing definitions are separate hypotheses. Count alone gives no exhaustion/reversal conclusion.

Prerequisites for each adjacent pair: verified OPEN, high, low and close; explicit RAW_EXECUTION and TECHNICAL_CONTINUITY prices with source/version and as-of validity; verified security-specific eligible sessions including suspension/resumption; verified corporate-action effective-date and adjustment provenance; tick/price-limit state. A real suspension is not a missing calendar bar and a provider's zero-volume flat pseudo-bar is not a candle. Ex-rights reset can create a raw gap that disappears after continuity transformation; a residual transformed gap can remain economically informative, so do not suppress the whole day by event flag. If the source returns adjusted data despite a raw request, block the raw comparison. Guard split/consolidation or trading-unit changes and odd-lot volume before any volume-conditioned variant.

Adversarial pairs: (A) ordinary rising three opens but overlapping high/low ranges -> three overnight gaps, zero non-overlap gaps; (B) three non-overlap upside gaps, third session closes weak -> event sequence observed, directional effect UNKNOWN; (C) ex-rights mechanical opening reset -> raw gap, technical gap absent; (D) ex-rights residual move -> transformed residual gap can survive; (E) consecutive limit-up bars -> gaps may be observable but acceptance/price discovery UNRESOLVED until unconstrained eligible session; (F) suspension pseudo-bar between observations -> must be removed only with authoritative security session proof; (G) one absent OPEN or uncertain adjustment -> DATA_BLOCKED, never count two or three by treating UNKNOWN as zero.
