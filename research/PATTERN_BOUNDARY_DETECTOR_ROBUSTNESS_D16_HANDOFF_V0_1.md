## Purpose

D01 owns structural semantics and perturbation generation.
D16 owns future statistical inference.

## Frozen comparison object

The statistical unit remains the immutable parent / relation episode.

Boundary and detector perturbations are nested sensitivity views of the same parent and never multiply independent N.

Future D16 analysis must:

1. preserve equal or explicitly justified parent/date weighting;
2. report coverage for every perturbation family;
3. keep canonical, legal-grid, anchor-jackknife and detector-version results visible;
4. use common-support parent sets for cross-version effect comparisons;
5. report identity disappearance/change separately from outcome performance;
6. preserve scan-date and symbol dependence;
7. use chronological OOS / purged holdout where outcomes eventually open;
8. account for the broader Pattern experiment family and existing multiple-testing governance;
9. never select the perturbation set, detector version or jackknife subset using observed returns.

## Robustness is not majority vote

A parent with four nearby boundary variants is still one parent.

Do not treat variant count as sample count.

Recommended future reporting is a parent-nested sensitivity matrix with:
- effect estimate under canonical;
- range / sign stability across frozen perturbations;
- coverage;
- identity-stability rate;
- detector-version common-support rate;
- failure / not-evaluable reasons.

D01 does not freeze the exact estimator, p-value method or confidence-interval method.
