# 自我進化學習研究室 — 研究輸出強制契約

Status: CANONICAL_OUTPUT_CONTRACT
Scope: 01～11 專屬研究室，手動研究＋自動學習
Priority: 本檔為研究「可見輸出格式」最高優先契約；若其他舊檔範例與本檔不同，以本檔為準。

## 每輪開始前

開始任何實際研究之前，先顯示：

【本輪開始】YYYY/MM/DD HH:MM（台北時間）

【本輪執行指令】進行深度研究學習與反證，長段落研究模式，依總控規則執行，每個英文單字後面都必須加上中文解釋

顯示後才可開始研究。

## 可見文字語言契約

### 原則 A：優先寫中文

可用中文清楚表達時，優先直接寫中文，降低不必要的裸英文。

### 原則 B：每一個一般英文單字都逐字緊接中文

正確：
- Forecast（預估） Freshness（新鮮度）
- Consensus（共識） Accuracy（準確度）
- Volume（成交量） Profile（分布）
- Moving（移動） Average（平均線）
- Market（市場） Regime（狀態）
- Historical（歷史） Validation（驗證）
- Quality（品質） Shadow（影子驗證）
- GitHub（程式碼託管平台）
- Tracker（進度追蹤器）
- alpha（超額報酬）

錯誤：
- Forecast Freshness（預估新鮮度）
- Volume Profile（成交量分布）
- Moving Average（移動平均線）
- Market Regime（市場狀態）

只要片語中有任何一個英文單字沒有立即跟中文，該輸出即不合規。

### 原則 C：機器原樣字串不可拆

GitHub 路徑、檔名、URL、commit SHA、程式碼、JSON key、函式名、正式資料欄位、模組 ID、status code／enum value 等 machine literal（機器原樣字串）必須用反引號包住，整串後面加中文解釋：

- `main`（主分支）
- `SOURCE_BLOCKED`（資料來源阻塞）
- `LONG_BLOCK_STAGE_VII_COMPLETE`（長區塊第七階段完成）
- `D08-03`（D08 第 03 模組）
- `research/stock_market_learning_tracker_v0_1.json`（正式研究進度追蹤檔）

不得拆開或翻譯機器原樣字串本體。

## 每輪結尾固定格式

【GitHub（程式碼託管平台）寫回與續接／本輪總控進度】

每個本研究室正式負責的 Dxx 都顯示：
- Dxx｜領域名稱　正式百分比
- 20 格文字進度條
- 重點：本輪新增證據／反證／阻塞／為何升級或維持

【全體研究模組】
- 正式整體百分比
- 20 格文字進度條
- 整體重點說明：最新正式總模組數、整體進度來源、本輪實際影響；若未升級須明寫沒有藉工程完成提高成熟度。

【學習進度】
- 研究室／領域
- 本輪完成
- 當前模組
- Level（等級）
- 成熟度
- 狀態
- 下一續接點

最後：
- 本輪開始
- 本輪結束
- 本輪耗時
- YYYY/MM/DD HH:MM（台北時間）

## 非正常中斷

顯示【非正常中斷】，至少包含：
- 本輪開始
- 中斷確認
- 已持續時間
- 中斷原因
- 最後完成點
- GitHub（程式碼託管平台）／checkpoint（檢查點）寫回狀態
- 下一續接點
- 日期與台北時間

UI（使用者介面）顯示「思考中」不能證明仍持續執行；沒有可驗證執行證據時必須標 UNKNOWN（未知）或可能中斷。

## 送出前強制雙檢

第一檢：確認開始標記、固定執行指令、進度條、重點說明、全體進度、學習進度、開始／結束／耗時均齊全。

第二檢：掃描所有可見 A-Z／a-z。除反引號包住的 machine literal（機器原樣字串）外，每一個英文單字都必須立即有中文括號解釋。

只要有一個裸英文，不得稱為完全合規，狀態記為：
`LANGUAGE_GATE_FAIL`（語言閘門失敗）。
